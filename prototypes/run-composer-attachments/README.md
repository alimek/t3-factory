# Run composer attachment prototype

Throwaway design source for [Composer screenshot attachment UI and Flow input thumbnails](https://github.com/alimek/t3-factory/issues/103), part of the screenshot wayfinding map.

Open `index.html` directly in a browser for the selected inline layout and clickable image references. `variants.html` preserves the three original layouts; use its arrows or `?variant=A`, `?variant=B`, `?variant=C`.

Everything runs in memory. Example screenshots are generated illustrations. Start and unknown-outcome states are simulated; the prototype sends no API requests and does not save drafts. The separate Run-screen preview in the original variants is a comparison, not part of the composer. Product behavior and accepted decisions live in the linked issue.

This branch is a design reference and must not be merged. Implement the accepted behavior with Factory's existing UI primitives and design tokens. Native T3 context references are not generated by this prototype.
