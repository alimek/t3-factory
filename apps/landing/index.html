FEATURES

Your process, as a Flow you can run.

Factory does not impose a development process. You decide the blocks and exits.

DESIGN

Design Flows visually

Connect Agent and Human blocks with named exits, correction loops and parallel branches. Save unfinished drafts and check readiness before you run.

  • Named exits and correction loops
  • Independent parallel branches
  • Readiness checks before launch

AGENTS

Reuse Agents across projects

Save a prompt and worker settings once. Factory launches each Block with that Agent's provider and model, in any project.

  • Prompt and execution settings
  • Per-Agent provider and model
  • Immutable revisions

HUMANS

Keep decisions with people

Answer Human steps in Factory and open T3 for native agent questions or permissions. See at a glance which Runs need input.

  • Approve or request corrections
  • Needs-input and Problem states
  • Jump to the T3 conversation

RUNS

Follow durable execution

Inspect the execution canvas, handoffs and timeline. Each Run keeps its captured definitions and history across restarts.

  • Live execution canvas
  • Handoffs and timeline
  • Settle, archive or start again
