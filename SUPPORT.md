# Support

T3 Factory is in early development. Support is best effort; there is no guaranteed
response time or production support commitment.

## Where to ask

- **Setup and usage:** start with the [README](README.md),
  [installation guide](docs/installation.md) and [T3 integration](docs/t3-integration.md).
- **Bugs:** search [existing issues](https://github.com/alimek/t3-factory/issues), then
  use the [bug report form](https://github.com/alimek/t3-factory/issues/new?template=bug_report.yml).
- **Ideas:** use the [feature request form](https://github.com/alimek/t3-factory/issues/new?template=feature_request.yml)
  and explain the workflow you want to improve.
- **Questions:** open an [issue](https://github.com/alimek/t3-factory/issues/new)
  with your question and what you have already tried.
- **Vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not post exploit details publicly.

## Useful diagnostic information

Include the Factory commit or desktop build identity, OS and architecture, Node and
pnpm versions for a source install, and whether you used the demo, source production
or desktop. For integration problems, include T3/harness versions and the relevant
permission mode. Give the shortest reproduction and the expected and actual result.

Share only a small, redacted error excerpt. Remove tokens, OAuth callback URLs,
credentials, private prompts, repository paths and host/device identifiers. Do not
upload a Factory database, data home or complete trace by default.

The [compatibility limits](docs/installation.md#compatibility-and-support-limits)
distinguish controlled checks from live integration and supported release targets.
